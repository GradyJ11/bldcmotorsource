# BLDC Motor Resources

A curated collection of resources for researching,
selecting and understanding brushless DC (BLDC) motors.

This repository covers BLDC motor specifications,
selection criteria, applications, manufacturers,
terminology and technical references.

- KV, torque and RPM
- Robotics motor applications

- Gimbal motors
- Frameless motors
- BLDC motor manufacturers
- Technical terminology
